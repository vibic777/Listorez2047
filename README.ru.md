# Листорез2047 (Listorez2047)
[English](README.md) · [Русский](README.ru.md)

> Одна прикладная задача по работе. Сразу сделан универсально: для однотипных документов. Проект завершён.

**Листорез2047** вырос из одной рабочей задачи: нужно было разобрать пачку одинаковых по форме документов. Делал, как обычно, не под единственный случай, а так, чтобы тем же способом закрывать похожие пачки.

Что делает:

- режет многостраничный PDF на **один файл на страницу**
- называет каждый файл по шаблону
- использует OCR только для имени, не для пересказа документа
- даёт проверить страницы в окне или прогнать ту же работу из командной строки

Это законченный офлайн-инструмент.

## Антивирус / VirusTotal (ложные срабатывания)

Отдельные движки на [VirusTotal](https://www.virustotal.com/) могут пометить portable-сборку Windows. Это **ложное срабатывание на способ упаковки**, а не троян в программе или в RapidOCR/Qt.

**Почему так**

- Релиз — **PyInstaller `--onefile`**: при запуске exe сам распаковывает Python, DLL и модели OCR во временную папку (`%TEMP%\_MEI…`) и стартует оттуда. Так же ведут себя настоящие дропперы, поэтому эвристика часто пишет `Dropper.Agent` / общее «malware».
- Файл **не подписан** сертификатом. Неподписанный самораспаковывающийся PE режется жёстче.
- Сборка **без UPX** (`--noupx`), чтобы не добавлять ещё один типичный триггер.

**Что обычно видно на VirusTotal** (та же упаковка; несколько движков из ~60+)

| Движок (примеры) | Вердикт | Смысл |
|---|---|---|
| Zillya | `Dropper.Agent.Win32…` | Эвристика: упакованный / самораспаковывающийся агент |
| Общие / ML | `W32.Malware.…` / «Suspicious» | Эвристика по структуре/хешу, не конкретная семья вируса |
| (для zip) SentinelOne Static ML | `Suspicious Archive` | PE внутри архива |

Остальные движки — **Undetected**. Исходники и запуск `python -m listorez2047` так не клеймят — срабатывает однофайловый лаунчер.

**Как проверить релиз**

1. Скачивайте только с [GitHub Releases](https://github.com/vibic777/Listorez2047/releases/latest).
2. Сверьте SHA-256 из заметок релиза с вашим файлом.
3. Откройте хеш на VirusTotal: `https://www.virustotal.com/gui/file/<SHA256>`.
4. Если антивирус удаляет файл — добавьте исключение для этой известной программы или запускайте из исходников.

Подпись кода (code signing) в будущем снизит шум SmartScreen/AV; для работы программы она не обязательна.

## Зачем это

OCR (RapidOCR / PP-OCRv5, только CPU) нужен **только чтобы собрать имя файла**. Страница копируется в новый одностраничный PDF как есть. Скан — картинка; цифровой PDF уже содержит буквы.

У поля задаётся значение по умолчанию. «Вычислять выражение» — формула в **значении по умолчанию**, не в паттерне OCR: `{235:+1}` даёт 235, 236… по номеру листа; также `{505:+1#}`, `{1:+1}`, `{20:-1}`, `{2:*2}`, `{0:%10}`. OCR этой рамки не нужен. Ошибка в формуле или паттерне — предупреждение, программа не закрывается. «Запоминать последнее значение» переносит на следующую страницу последнее **применённое** значение (после правки человека, по «Применить» или «Сохранить»), а не сырой OCR.

**Автомат** распознаёт страницы в фоне. Предпросмотр остаётся доступным: масштаб, сдвиг, «Сохранить вид». Пустые поля останавливают пакет для проверки.

## Командная строка

Это настольная программа: без параметров открывается графический интерфейс. Справка и версия выводятся без запуска Qt:

```text
Listorez2047.exe --help
Listorez2047.exe -h
Listorez2047.exe --version
python -m listorez2047 --help
```

Параметров для передачи PDF и папки вывода нет — выберите их в интерфейсе.

## Возможности

- Цифровой PDF и сканы
- Предпросмотр: зум, вписать, пан; рамки привязаны к странице
- Шаблон `{1}`, `{2}` и счётчики `{505:+1}` / `{1:+1#}` (`+ - * %`), ручная правка имени
- Постранично и **Автомат**
- Профили `.pdfocr.json`
- Интерфейс русский / английский, четыре скина и четыре иконки
- Новая иконка Листореза используется по умолчанию и в Windows exe
- Журнал DEBUG / INFO / WARNING / ERROR / CRITICAL (сбои Qt тоже пишутся)
- Portable: один `Listorez2047.exe` (Windows) или один бинарник `Listorez2047` (Linux)

Железо: около **4 ГБ RAM**, **2–4 ядра CPU**. Страницы обрабатываются последовательно, OCR работает на CPU. Для OCR растеризуется область поля с ограничением максимальной стороны; предпросмотр рендерится отдельно.

## Требования (из исходников)

- Python 3.11 или новее, 64-bit
- Windows 10/11 или Linux x64
- [requirements.txt](requirements.txt) — PySide6 6.9.3, RapidOCR; без Surya / PyTorch / CUDA
- Для тестов: `python -m pytest` (если pytest не установлен, установите его отдельно).

## Запуск из исходников

```bash
python -m pip install -r requirements.txt
python scripts/download_ocr_models.py
set PYTHONPATH=src
python -m listorez2047
```

Загрузка моделей нужна только для запуска из исходников. Готовое приложение содержит модели PP-OCRv5 и не обращается к сети при распознавании.

Linux / macOS: `export PYTHONPATH=src` и `python3 -m listorez2047`.

Журнал **по умолчанию выключен**. При включении выбираются уровни TRACE / DEBUG / INFO / WARNING / ERROR / CRITICAL. Путь из исходников: `%APPDATA%\Listorez2047\Listorez2047.log`.  
У собранного exe — `Listorez2047.log` рядом с `Listorez2047.exe`.

Папка результата — абсолютный или относительный путь (галка); сохраняется в профиле. Если папки нет — программа предложит создать её.

Настройки: `%APPDATA%\Listorez2047\config.json`. Если рядом с exe лежит `config.json`, берётся он (портативный режим). Старые папки `%APPDATA%\PDFOCRsplitter` и `%APPDATA%\Listorez` читаются, пока новой ещё нет.

## Сборка

Скрипты сборки загружают модели PP-OCRv5 из официального репозитория RapidOCR и проверяют их SHA-256.

```powershell
powershell -File scripts/build_windows.ps1
```

Результат: `dist/Listorez2047.exe`. Папка (быстрее старт): `powershell -File scripts/build_windows.ps1 -Onedir`.

Linux: `bash scripts/build_linux.sh` → `dist/Listorez2047`.

Очистка: `powershell -File scripts/clean.ps1` (не трогает исходники, `.venv` и пользовательский config).

## Надёжность и ограничения

- Страница сначала сохраняется во временный файл в папке результата; существующий файл не перезаписывается.
- Профиль записывается атомарно. Геометрия полей проверяется при загрузке.
- Если Auto не смог распознать страницу, ошибка попадает в отчёт, а страница не сохраняется. Пустые и неоднозначные значения открывают проверку.
- OCR работает через RapidOCR 3.9.2 и модели PP-OCRv5 ONNX на CPU. Скрипт сборки загружает пять нужных моделей из официального репозитория RapidOCR на ModelScope и проверяет SHA-256; в готовое приложение модели включены, поэтому интернет при работе не нужен.
- Автовыравнивание исправляет небольшой перекос OCR-вырезки. Потоки CPU, языки распознавания, размер детектора и размер пакета применяются к ONNX. Модели языков загружаются по очереди, в памяти одновременно находится одна.

## Паттерны

- `DD.M.DDDD` — полная дата с месяцем цифрой или словом → `01.06.2026`
- `DD.M` — день и месяц без года: `«27» марта 2026 г.` → `27.03` (кавычки и год пропускаются)
- `@{№}D{1,4}` — контекстный якорь для номера; `№`/`No` ловится, но не попадает в значение
- `D{1,4}` / `C+` — переменная длина без нулей слева
- `DD.DD.DDDD` — дата только цифрами, с нулями

Справка в программе: **F1**. Шпаргалка: **F2**.
