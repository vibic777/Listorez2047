How to use Listorez2047

Listorez2047 splits a PDF into one file per page and names each file from a template. OCR is only for the filename. The page content is copied as-is.

Digital PDF vs scan

  • Digital — the PDF has a text layer. With OCR off, values come from the field rectangle; with OCR on, the app tries the text layer first on digital pages.
  • Scan — the page is only an image. Enable the OCR checkbox, or type values by hand.

Typical steps

  1. Open a PDF. Pick an output folder (absolute or relative to the PDF folder; missing folders can be created).
  2. Load a profile or draw fields on the preview. Overlapping frames are allowed: each field has Clip / Recognize.
  3. A default is fixed when both options are off. Evaluate expression supports the filename formulas; Remember last value copies the last applied value (after a human correction, on Apply or Save) to the next page. Raw OCR is not remembered by itself. The options are mutually exclusive.
  4. Set the filename template, for example Acceptance act No.{1} from {2}.
  5. Recognize the page, edit values if needed, Save — or press Auto to process the whole file.

Filename template

{1}, {2} insert field values. {505:+1#} numbers in save order (skips do not count). {1:+1} is the page number in the PDF. The same formulas as a field default belong in the default value (for example {235:+1}) with Evaluate expression; not in the OCR pattern. Remember last value instead carries the last applied text (after a human correction) to the next page; raw OCR is not stored by itself. The two options are mutually exclusive; both off means a fixed default.

A bad pattern, or a filename formula left in the OCR pattern instead of the default value, does not close the app: a warning is shown, that frame yields an empty result, and you can fix it and continue.

Field patterns

Open Cheat sheet (button ? or F2) for the token table: D digit, H/h hex, C letter, {0-9} digits, and so on. After OCR the text is normalized to the pattern. If it still does not match, type the value yourself.

For an all-numeric date use DD.DD.DDDD. If the month may be numeric or a word (“01 June 2026”), use DD.M.DDDD; the filename receives 01.06.2026. If you do not need the year, use DD.M: “27” 03 2026 г. becomes 27.03, and “27” March 2026 г. also becomes 27.03. Quotes and text after the month are not included; month names are converted to digits. For a variable-length number use D{1,4} or D+ to avoid leading-zero padding. For a variable-length name use C{1,12} or C+.

A context anchor @{text} requires a marker in the recognized text but does not emit it. Separate alternatives with |. For example:

  • @{№}D{1,4}: № 216 or No 216 → 216. Common OCR forms No, Nº, and N° are accepted automatically for №.
  • @{ИНН|INN}D{10,12}: ИНН 7701234567 → 7701234567; the Latin marker also works.
  • D{1,4}@{руб}: 216 руб. → 216; the anchor may follow the number.

Use an anchor when its marker distinguishes the desired value from other numbers. Anchors filter recognized text; they cannot restore characters the OCR missed.

Complete example: field 1 “Number” with D{1,4} recognizes 22; field 2 “Date” with DD.M.DDDD recognizes 1 June 2026. Template Act_{1}_from_{2} produces Act_22_from_01.06.2026.pdf.

Frames and field selection

Click a frame to select its field in the list. Click a list field to highlight its frame. Drag the middle to move a frame; drag the square handle at the lower-right corner to resize it.

Enter exact X, Y, width and height in page percent, preview pixels, millimetres, or centimetres. Contrast is stored per field and included in profiles. Use Remove gray paper background for faint gray pencil on off-white paper. The visible −, + and Fit controls adjust the preview, and Auto preserves its zoom and position between pages.

To process a page again, right-click it and choose Reset page to pending. This does not delete an existing output file.

Three ways to work

  • Auto recognizes sequentially on a background thread. Preview stays usable: zoom, pan, and Save view. Auto progress is non-modal. The pause/review dialog is also non-modal, so preview zoom and pan still work. While the app is running, progress and review stay where you dragged them; a restart puts them back. Configuration has a reset. Restarting skips saved/skipped pages and preserves manual corrections.
  • Per page — Recognize page → check → Save or Next.
  • By hand — “Manual field input” (F6) opens every field with existing recognized values. Editing immediately rebuilds the filename; Enter applies the values and saves the PDF, Alt+S skips the page, and Esc cancels input.

If a field is empty, review shows every field, template, and filename. Each value is a dropdown with the scan result and the default; you can also type your own. For faint pencil, set that field's contrast to 2.0–3.0 and press Retry field. Only that frame is recognized again, then a choice dialog offers the new scan result or the default. The same review appears after manual recognition and before saving with an empty field.

Default value is configured next to the pattern. If OCR finds nothing, review opens with this text instead of an empty input. The fallback does not bypass mandatory review.

OCR engines and error log

Recognition uses RapidOCR / PP-OCRv5 on CPU. Surya, PyTorch, Transformers, and CUDA are not used. Contrast and preprocessing can be set on the field immediately — they apply to the first Recognize page and to Auto, not only on Retry field.

The same dialog enables logging (off by default) and selects its path. Levels are checkboxes: TRACE, DEBUG, INFO, WARNING, ERROR, CRITICAL — all on by default when logging is enabled. Startup, OCR, saves, and unhandled Qt failures are recorded. A packaged exe writes Listorez2047.log next to the program; from source the default is AppData\Listorez2047.

The preview has four controls: minus, plus, Fit, and Save view. Save view makes the current zoom and center the default for subsequent pages in the open document and Auto.

Profiles

Save the field layout, template, OCR settings, and output folder to a profile and load it on another PDF of the same form. One profile per open file. Auto-deskew corrects small skew angles in the OCR crop.

Configuration

Default OCR DPI is 300. RapidOCR 3.9.2 runs PP-OCRv5 ONNX models on CPU. CPU threads, detector size, and recognition batch are applied to ONNX. Selected languages run sequentially with one language model in memory at a time. Faint-text contrast 1.0 means no enhancement; try 2.0–3.0 for light pencil. Excessive contrast can amplify paper noise. “Cyrillic (Russian)” is for Russian text; “Latin” covers English and other Latin-script languages. Default OCR strategy is assigned to new field frames. Reset window positions puts progress, review, and other dialogs back in this session (positions are not stored across restarts).

Custom page format displays width and height. Choose mm, cm, or inches; changing units converts the values while preserving physical size. For example, 210 × 297 mm equals 21 × 29.7 cm.

The command line only provides help: Listorez2047.exe --help or -h lists options, and --version prints the version. With no options the GUI opens. PDF and output-folder CLI arguments are not supported.

Faint-pencil strategies

  • Standard — no special processing.
  • Local contrast (CLAHE) — first choice for faint pencil; start at 2.0.
  • Remove gray paper background — evens out off-white paper and isolates thin light-gray pencil strokes; start at 2.0–2.5.
  • Adaptive threshold — uneven or gray paper.
  • Remove horizontal lines — suppresses a heavy underline before OCR.
  • Upscale and sharpen — small, thin writing.

If standard OCR is unsure or its result does not match the field pattern, the app retries with local contrast and enlargement, adaptive black/white processing, and horizontal-line removal. Distinct results that match the pattern appear first in the choice dialog; retries can take longer. Enable “Cyrillic (Russian)” for Russian and “Latin” for English; enable both for mixed-language fields. PP-OCRv5 reports improvements for handwritten English, but cursive and Russian handwriting are not guaranteed. Review the proposed value and correct it manually when needed.

Choose a strategy on the field editor immediately, from the first recognize. In review you can change it and press Retry field. A choice dialog then offers the new scan result or the default; you can also type your own. OCR renders the field region rather than the full page and applies the configured maximum raster side. Try another strategy if needed; handwriting cannot be guaranteed, so manual input remains available.

Numeric limits

DPI 100–600; OCR side 800–10000 px; CPU 1–4; score 0–1; detector 320–4096; batch 1–32; padding 0–50%; contrast 1.0–4.0. Mouse arrows and ↑/↓ stop at these limits. Frame X/Y stay on the page and width/height cannot cross its right or bottom edge.

Common problems

  • Empty field — draw a larger rectangle or type the value.
  • Wrong snippet — several matches: pick one in the popup or in the review dropdown (scan / default). Auto has no that popup during batch OCR, but an empty field pauses the batch.
  • Small skew — enable Auto-deskew in the OCR settings. For a 90° or 180° rotation, use the page rotation controls.
  • Password-protected PDF — the file will not open; remove the password first.
